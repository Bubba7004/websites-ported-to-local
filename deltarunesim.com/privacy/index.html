The short version: no accounts, no ads, no cookies set by the site, and nothing that identifies you. Your saves stay in your browser. A few anonymous numbers about finished fights and bugs are sent back, and one switch turns that off.

What stays on your device

Settings, progress, achievements, replays and anything you import (such as MANIA beatmaps) are kept in your browser's own storage (local storage and IndexedDB). They are never uploaded. Clearing this site's data in your browser deletes them.

What is sent, and why

Anonymous fight stats

When a fight ends, the game sends one small row: which fight and chapter, whether it was won, lost or left, hits taken, how long it lasted, enemy turns, the run options and game speed, whether autoplay or another assist was used, and the app version. The server adds the time. The totals are public on the fight stats page.

Bug reports

To find and fix bugs, the game also sends short reports that only the developer reads: errors in the game's own code (with web addresses, file paths and any quoted text removed), fights that freeze, frame-rate numbers with a rough device type (browser and version, touch screen or not, screen size, processor cores and memory in broad groups), files that would not load, and where fights are won, lost or left.

Desktop app downloads

When you download the desktop app from this site, or with the install commands on the download page, the server counts the download: which file, whether it came from the page or an install command, and the day. Your IP address is not stored: to count each sender once a day and stop repeated requests from adding up, the server keeps a one-way hash of the address mixed with a secret that changes every day, and deletes it after a day.

What is never sent

No name, no account, no cookie, no player or visit ID, and nothing you type. Your IP address is not stored: to stop floods, the server counts posts per sender using a one-way hash of the address mixed with a secret that changes every day.

How to turn it off

In the game, open CONFIG, then SYSTEM, and turn off Share anonymous stats and bug reports. If your browser sends Do Not Track or Global Privacy Control, nothing is sent at all.

Hosting

The site is hosted on Cloudflare Pages. Like any web host, Cloudflare handles each request (including your IP address) to deliver the page and protect it from abuse, and it may set a short-lived security cookie when it checks for automated traffic. Cloudflare's privacy-focused Web Analytics may count page views; it uses no cookies and does not follow you to other sites.

Other sites

The game only contacts other hosts when you ask it to: MANIA's download tab searches public osu! beatmap mirrors when you use it. Links to Discord and X open those sites, under their own privacy policies.
